Build memory like software.

Strata is a content build system for RAG and agent-memory pipelines: it fingerprints sources, plans the smallest rebuild, runs pluggable operations, and records lineage from document to sink.

Prototype release

Local-first, SQLite-backed, plugin-oriented. Built to validate the core loop before durable executors and production artifact stores.

What problem does it solve?

RAG pipelines look simple until documents change, chunking config is revised, embedding dimensions change, or a sink write partially succeeds. Strata treats those pipelines like build graphs instead of scripts: each asset has a stable identity, each output is cataloged, and each downstream rebuild follows from fingerprints.

The core stays deliberately small. Sources, operations, artifact collections, sinks, and runners are all adapter boundaries. Today the built-ins cover local files, object-store-like folders, fixed chunking, fake embeddings, local JSON artifacts, SQLite state, and local runners.
